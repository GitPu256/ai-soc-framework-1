📋 Project Overview

Modern SOCs face high alert volume, limited interpretability of AI decisions, and weak governance. This capstone delivers a prototype AI-Enabled SOC Architecture that integrates deterministic triage, explainability, and human-in-the-loop controls.

🏗️ Architecture

  • Layer 1: Data Ingestion & Normalization
  • Layer 2: AI-Based Threat Detection
  • Layer 3: Explainable AI Triage
  • Layer 4: Governance & Human-in-the-Loop Response
